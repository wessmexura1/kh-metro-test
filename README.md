# Харківський метрополітен: перевір себе

Статичний адаптивний сайт українською мовою: 12 запитань, SVG-схема з 30 актуальними назвами станцій, результат, розбір помилок, офіційні джерела та оригінальний референс.

## Запуск

Потрібен Node.js. Залежностей для запуску немає.

```sh
npm run dev
```

Адреса: http://127.0.0.1:5174/ . Для звичайного статичного хостингу завантажте вміст `dist`.

```sh
npm test
npm run check
```

## Структура

- `dist/js/data.js`: запитання, стійкі ID варіантів, пояснення, офіційні джерела та зафіксована дата перевірки.
- `dist/js/metro.js` і `map.js`: лінії, назви станцій, пересадки та SVG.
- `dist/js/state.js`: стан спроби, перемішування й підрахунок результату.
- `dist/js/storage.js`: перевірка й збереження прогресу, обробка помилок localStorage.
- `dist/js/screens.js`: п’ять екранів інтерфейсу.
- `dist/js/app.js`: hash-навігація, радіогрупи, діалоги та необов’язкові WebMCP інструменти.
- `dist/js/animation.js`: необов’язкова GSAP анімація, зупинка, очищення та reduced motion.
- `tests/quiz.test.mjs`: перевірки стану, результатів, даних і відновлення.

Результати не надсилаються на сервер. Збереження й найкращий результат прив’язані до цього браузера та версії запитань. Нові версії даних потребують явної зміни `QUESTION_VERSION` після перевірки джерел.

## Джерела та перевірка

Офіційні сторінки перевірено **04.10.2026**. На синій лінії — «Ярослава Мудрого» та «Салтівська»; на червоній — «Вокзальна», «Левада», «Заводська». У початковому зображенні є старі назви та користувацькі помітки.

Вихідна адреса червоної лінії `/kholodnohirsko-zavodska-liniia/` виявилася недоступною. Використано доступну офіційну адресу `/kholodnohikrsko-zavodska-liniia/` (написання URL збережено саме як на сайті).

Локальні файли e-Ukraine Regular/Bold отримано з архіву, на який посилається Міністерство цифрової трансформації: https://thedigital.gov.ua/fonts . Атрибуція міністерства й CC BY 4.0 включена в сторінку джерел. GSAP 3.13.0 та MotionPathPlugin збережено локально; їх заголовки з інформацією про ліцензію збережено. Жодних зовнішніх запитів для роботи тесту не потрібно.

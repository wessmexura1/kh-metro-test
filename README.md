# Харківський метрополітен: перевір себе

Статичний адаптивний сайт українською мовою: 12 запитань, SVG-схема з 30 станціями, результат і розбір відповідей з офіційними джерелами.

## Запуск

Потрібен Node.js. Залежностей для запуску немає.

```sh
npm run dev
```

Адреса: http://127.0.0.1:5174/ . Для статичного хостингу використовуйте вміст `dist`.

```sh
npm test
npm run check
```

## Структура

- `dist/index.html` і `styles.css`: спільний каркас та єдина таблиця стилів.
- `dist/js/data.js`: запитання, ID варіантів, пояснення, офіційні джерела та дата перевірки.
- `dist/js/metro.js` і `map.js`: лінії, назви станцій, пересадки та SVG.
- `dist/js/state.js`: стан спроби, перемішування й підрахунок результату.
- `dist/js/storage.js`: перевірка й збереження прогресу, обробка помилок localStorage.
- `dist/js/screens.js`: головна, запитання, результат і розбір відповідей.
- `dist/js/app.js`: hash-навігація, радіогрупи, збільшення схеми та необов’язкові WebMCP інструменти.
- `dist/js/animation.js`: початкова поява схеми та рух поїздів на трьох лініях.
- `tests/quiz.test.mjs` і `motion.test.mjs`: 20 перевірок даних, стану, відновлення, спрощеного інтерфейсу та координат станцій.

Поява ліній і станцій відтворюється лише при першому показі головної після відкриття сторінки. По кожній лінії поїзд безперервно проходить станції в обидва боки з короткими зупинками. Рух можна призупинити кнопкою у заголовку схеми. Анімація зупиняється поза екраном і в прихованій вкладці, очищується при переході до тесту та враховує налаштування reduced motion. Бібліотеки завантажуються лише за потреби; відмова анімації не перешкоджає тесту.

Результати не надсилаються на сервер. Прогрес і найкращий результат прив’язані до браузера та версії запитань. Після зміни перевірених даних потрібно явно оновити `QUESTION_VERSION`.

## Браузерна перевірка

`tests/browser.mjs` перевіряє повні спроби 0/12 і 12/12, відновлення прогресу, перемішування, клавіатуру, фокус і Escape діалогу, пошкоджене й недоступне сховище, відмову GSAP, reduced motion, одноразову появу схеми та циклічний рух на всіх трьох лініях. Перевірено ширини 320/390/844 px та WCAG A/AA через Axe на всіх чотирьох екранах.

Необов’язкові інструменти перевірки встановлюються поза проєктом. У PowerShell:

```powershell
$qaDirectory = Join-Path ([System.IO.Path]::GetTempPath()) 'kharkiv-metro-qa'
npm install --prefix $qaDirectory --no-audit --no-fund playwright-core @axe-core/playwright
node tests/browser.mjs
```

Перед запуском відкрийте локальний сервер. Сценарій використовує системний Microsoft Edge та створює тимчасові знімки й звіт у `test-artifacts`.
